# E13.1: the fixed cost of synchronised phases

Thread pool, one task per worker per phase, tasks doing nothing; natively. A step has 24 phases, of which 6 must be synchronised. For scale: a step of the thesis grid takes about 110-150 ms on 6-12 workers (E09.1).

| Interpreter | Workers | One synchronised phase | Step, every phase synchronised | Step, block-local phases merged | Share of a 120 ms step (all / merged) |
|---|---|---|---|---|---|
| free-threaded | 1 | 26 µs | 0.59 ms | 0.14 ms | 0.5 % / 0.1 % |
| free-threaded | 6 | 64 µs | 1.59 ms | 0.39 ms | 1.3 % / 0.3 % |
| free-threaded | 12 | 131 µs | 3.31 ms | 0.81 ms | 2.8 % / 0.7 % |
| with GIL | 1 | 32 µs | 0.76 ms | 0.19 ms | 0.6 % / 0.2 % |
| with GIL | 6 | 110 µs | 2.64 ms | 0.64 ms | 2.2 % / 0.5 % |
| with GIL | 12 | 192 µs | 4.61 ms | 1.12 ms | 3.8 % / 0.9 % |
