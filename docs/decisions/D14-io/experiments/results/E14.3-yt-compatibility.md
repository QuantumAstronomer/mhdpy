# E14.3: reading mhdpy's blocks with yt through Athena++'s layout

400 x 100 cells in 16 blocks of 50², Morton order, 6 primitive variables plus a group of mhdpy metadata; Python 3.14.8, NumPy 2.5.4, h5py 3.16.0, yt 4.4.2.

Fields recognised by yt: athena_pp/press, athena_pp/r0, athena_pp/rho, athena_pp/vel1, athena_pp/vel2, athena_pp/vel3.

Examples of derived fields yt provides from them: gas/density, gas/pressure, gas/velocity_magnitude, gas/velocity_x.
