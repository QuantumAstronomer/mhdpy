# E06.2: ghost exchange and the grouping of variables

256 blocks of 64² cells, 6 variables, 2 ghost cells, periodic; natively, one thread; Python 3.14.8, NumPy 2.5.4, macOS-26.7.1-x86_64-i386-64bit-Mach-O. All variants give identical ghost cells: True. The last column relates the time to one evaluation of the time derivative of all blocks (66 ms at 1.6 × 10⁷ cells per second, E06.1).

| one array per module (hydro, scalars), 16 copies per block | 8.68 | 33.9 | 13.2 % |
| one array per variable, 48 copies per block | 17.30 | 67.6 | 26.4 % |
