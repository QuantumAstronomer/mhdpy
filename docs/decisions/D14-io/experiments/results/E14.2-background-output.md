# E14.2: writing snapshots in the background

Thesis grid (4000 x 1000, blocks of 50²), SSP-RK2 with ranged calls on a thread pool; a snapshot (five conserved variables, 160 MB) every 5 steps, 40 steps; natively, internal SSD. Cost of a snapshot: the extra time of the run over the same steps without output, per snapshot, in seconds and in steps.
