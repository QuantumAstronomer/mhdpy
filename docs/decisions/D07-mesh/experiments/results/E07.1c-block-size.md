# E07.1: block sizes on the thesis grid

Natively on macOS-26.7.1-x86_64-i386-64bit-Mach-O; NumPy 2.5.4. Million cell updates per second (one update = one full SSP-RK2 step of one cell), periodic grid, D06 layout and kernel, Python threads as in D05. ✓ = bit-for-bit identical to the single-block serial reference after two steps. 'Cells with ghosts' is the number of cells a block stores (and partly computes) per interior cell.
