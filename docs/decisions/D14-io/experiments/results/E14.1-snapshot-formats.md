# E14.1: writing a snapshot of the thesis grid

4000 x 1000 cells in blocks of 50², 6 primitive variables, interior cells only (192 MB in double precision). Python 3.14.8, NumPy 2.5.4, h5py 3.16.0 (HDF5 2.0.0), zarr 3.4.1, hdf5plugin 7.1.0; macOS-26.7.1-x86_64-i386-64bit-Mach-O, internal SSD. Best of three; reading with the file in the operating system's cache. Steps: the write with fsync in units of a thesis step (120 ms).
