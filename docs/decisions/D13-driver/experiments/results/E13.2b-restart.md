# E13.2: what a restart must contain

Sod, N = 400, SSP-RK2, CFL 0.4, step growth ≤ 1.1×, outputs every 0.025 hit exactly; interrupted at t = 0.1, continued in a new process to t = 0.2. Python 3.14.8, NumPy 2.5.4.

| Restart file | Bit for bit | Max. relative difference |
|---|---|---|
| state, time and previous step, binary | yes | 0.0e+00 |
| state and time only, binary | no | 3.8e-04 |
| everything as text, 10 significant digits | no | 1.0e-09 |
